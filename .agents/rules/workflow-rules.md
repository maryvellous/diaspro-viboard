# Workflow Rules — Separazione Pianificazione vs Esecuzione

## 🛑 Separazione Rigida tra Pianificazione ed Esecuzione

- **Fase di Pianificazione**:
  - Quando l'utente chiede di aggiornare la **roadmap**, un **log**, un **piano** o della **documentazione**, si trova in un **momento di pianificazione, non di esecuzione**.
  - Il compito dell'assistente consiste **ESCLUSIVAMENTE** nell'aggiornare il documento o la roadmap richiesta e **FERMARSI SUBITO**.
  - È fatto assoluto divieto di modificare il codice sorgente del progetto o implementare funzionalità prima di aver ottenuto l'autorizzazione esplicita.

- **Fase di Esecuzione**:
  - L'implementazione del codice e le modifiche ai file dell'applicazione avvengono **SOLO ED ESCLUSIVAMENTE** quando l'utente dà l'ok o la conferma a procedere con l'esecuzione della fase/piano.
